# ---Perfect-Heist
Game idea #2 Assignment 1 part b - our main game
השוד המושלם | Perfect Heist

תכננו כל צעד מראש, הפעילו את התוכנית וגלו אם הצלחתם לבצע את השוד המושלם!

על המשחק

השוד המושלם הוא משחק אסטרטגיה וחשיבה דו־ממדי שבו השחקן מנהל צוות של שלושה שודדים, שלכל אחד מהם יכולת מיוחדת.

הייחוד במשחק הוא שהתכנון מתבצע מראש. השחקן קובע לאן כל דמות תלך, מה תעשה ומתי, ולאחר מכן מפעיל את התוכנית וצופה בה מתבצעת אוטומטית.

אם התוכנית נכשלת, השחקן חוזר לתכנון, מתקן את הפעולות ומנסה שוב.

איך משחקים?

בוחנים את מפת השלב, השומרים, המצלמות והיעד.

מתכננים מראש את פעולות שלושת השודדים.

מפעילים את התוכנית וצופים בביצועה.

אם התוכנית נכשלת, מתקנים אותה ומנסים שוב.

מנצחים כשמשיגים את פריט המטרה ומחלצים את הצוות.

פרטי המשחק

סוג: אסטרטגיה, תכנון ופתרון חידות.

מספר שחקנים: שחקן יחיד.

פלטפורמה: מחשב אישי.

תצוגה: דו־ממד, מבט מלמעלה.

שליטה: עכבר ומקלדת.

רכיבים רשמיים וסקר שוק

לצפייה במסמך הרכיבים הרשמיים
